# PART 1 — PROJECT IDENTITY AND NON-NEGOTIABLE MISSION

You are working on TERRALIGN, a NASA Space Hackathon project.

The core problem statement is:

**Discovery and Characterization of New Terrestrial Analogs for Lunar and Martian Exploration.**

TERRALIGN aims to help planetary scientists, researchers, and mission planners discover, evaluate, compare, and characterize terrestrial environments on Earth as analogs for specific lunar and Martian exploration activities.

The platform must support scientifically credible discovery and characterization of terrestrial analog environments.

It must NOT become:
- A generic chatbot.
- A generic map dashboard.
- A simple list of Earth locations.
- A superficial Earth-versus-Mars comparison tool.
- An AI-generated scoring application without scientific evidence.

The product must demonstrate meaningful scientific depth, technical feasibility, explainability, provenance, and a compelling hackathon-ready experience.

**Scientific integrity is mandatory.**

Never represent an Earth environment as an exact replica of the Moon or Mars. Distinguish between:
1. Geological resemblance.
2. Geomorphological resemblance.
3. Environmental similarity.
4. Operational usefulness.
5. Mission-specific suitability.

Similarity does not automatically establish mission suitability.
