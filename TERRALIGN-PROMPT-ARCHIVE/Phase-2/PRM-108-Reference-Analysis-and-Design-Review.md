# PRM-108 — TERRALIGN | Reference Website Deep Analysis & Mission Command Design Review

## ROLE
Act as a Senior Product Designer, Creative Director, UX Architect and Immersive Experience Specialist.

Project: TERRALIGN — Where Earth Meets Other Worlds.

## OBJECTIVE

Our goal is to create TERRALIGN with an application experience comparable to the quality, visual sophistication, immersion and interaction experience of these two reference websites:

1. Obsidian Assembly: https://obsidianassembly.com/
2. UNESCO Virtual Museum: https://museum.unesco.org/

I do not want a basic dashboard with ordinary cards, panels and charts.

I want TERRALIGN to deliver a premium, immersive and visually impressive application experience, while implementing our own planetary science concept.

## PART 1 — REFERENCE WEBSITE ANALYSIS

Visit and study both websites.

Analyze their:

- Overall visual experience and identity.
- Navigation and user journey.
- Layout and screen composition.
- Typography and visual hierarchy.
- Cinematic presentation and lighting.
- Animations and transitions.
- Interactive elements.
- Spatial exploration experience.
- Scrolling and storytelling techniques.
- Responsive design.

Document the actual patterns observed. Do not invent features if a website cannot be accessed.

## PART 2 — TERRALIGN MISSION COMMAND DESIGN REVIEW

Inspect the existing TERRALIGN Mission Command design, HTML prototype and relevant specifications.

Evaluate how its current design could achieve a comparable premium and immersive experience.

The screen must retain its scientific purpose:

- Interactive planetary analog map.
- Seven flagship analog site profiles.
- Cinder Lake as the flagship location.
- Corrected Cinder Lake coordinates.
- Interactive location markers.
- Candidate selection and information panel.
- Suitability score and scientific breakdown.
- Mission overview and navigation.

Evaluate how the reference experiences can be translated into this screen without compromising scientific clarity or usability.

## PART 3 — DESIGN GAP ANALYSIS

1. Existing TERRALIGN design.

3. Identified design gaps.
4. Recommended improvements.
5. Expected user experience improvements.

## PART 4 — PROPOSED MISSION COMMAND DESIGN BLUEPRINT

- Overall screen composition.

- Transitions and animations.
- Responsive behaviour.

The proposed experience should feel premium, cinematic and immersive, not like a conventional administrative dashboard.
